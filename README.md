# AddogNepal
Dog adoption app for Nepal - College Project
A mobile application app for dog adoption in Nepal, built as a college project.

Features
- ✅ User Registration & Authentication
- ✅ Browse Available Dogs for Adoption
- ✅ Filter Dogs by Breed
- ✅ Search Dogs by Name/Breed
- ✅ Submit Dogs for Adoption (User)
- ✅ Review & Approve User Submissions
- ✅ Real-time Database with Firebase
- ✅ Responsive Design (Mobile & Desktop)

Technologies Used
- Frontend: HTML5, CSS3, JavaScript
- Backend: Firebase (Firestore, Authentication, Hosting)
- Icons: Font Awesome
- Deployment: Firebase Hosting
